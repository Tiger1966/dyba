# Dianyin Backend API 文档

## 1. 注册/登录一体化接口

- **路径**: `/api/register`
- **方法**: `POST`
- **Content-Type**: `application/json`
- **描述**: 提供手机号与密码进行注册或登录。如果手机号不存在，则创建新用户并注册；如果手机号已存在，则验证密码进行登录。

### 1.1 请求参数 (Request Body)

| 字段名 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `phone` | string | 是 | 11位中国大陆手机号，需满足正则 `^1[3-9]\d{9}$` |
| `password` | string | 是 | 密码，长度 8-32 位，必须同时包含字母和数字 |

### 1.2 响应参数 (Response Body)

**成功响应 (200 OK):**

```json
{
  "code": 200,
  "msg": "注册/登录成功",
  "data": {
    "user_id": 12345
  }
}
```

### 1.3 错误码表

| HTTP 状态码 | 业务状态码 (`code`) | 提示信息 (`msg`) | 触发场景 |
| :--- | :--- | :--- | :--- |
| 422 | 422 | (依赖具体参数报错) | 手机号格式不正确或密码不满足复杂度要求 |
| 401 | 401 | 密码错误 | 手机号已注册，但密码验证失败 |
| 409 | 409 | 手机号已存在 | 在并发场景下，多个请求同时尝试注册同一手机号 |
| 429 | 429 | 请求过于频繁 | 同一 IP 在 1 分钟内发起了超过 20 次请求 |
| 500 | 500 | (内部错误) | 数据库连接异常或其他服务器内部故障 |

### 1.4 curl 调用示例

```bash
curl -X POST http://localhost:8000/api/register \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "13800138000",
    "password": "Password123"
  }'
```

### 1.5 性能与安全说明

- **安全性**: 密码不在数据库中明文存储，采用 `bcrypt` (cost=12) 进行加盐哈希，杜绝日志打印明文密码。
- **防止 SQL 注入**: 数据库交互全部使用 `SQLAlchemy` 进行参数化查询，防止拼接注入。
- **并发处理**: 对于已存在手机号的数据读取采用 `SELECT ... FOR UPDATE` 行级悲观锁。
- **限流**: 每个 IP 1 分钟内最多允许调用 20 次接口。
- **性能**: P95 响应时间 < 200 ms，增量内存占用 < 5 MB。
