# Dianyin Backend

后端接口文档和部署说明。

## API 配置与密钥管理

本项目已集成对 DeepSeek 官方接口的异步调用。

在生产环境中，你可以在 `.env` 中添加以下变量，以覆盖代码中硬编码的默认 API 密钥：

```env
DEEPSEEK_API_KEY=你的真实_DeepSeek_API_KEY
```

这样后续需要替换密钥时，只需修改环境变量后重启服务即可。

### 修改服务器 IP (Base URL)
本项目支持使用环境变量动态配置返回资源时的公网 IP，消除代码中的硬编码，从而在服务器迁移时不再需要批量修改代码。

**操作步骤：**
1. 在项目根目录创建或编辑 `.env` 文件。
2. 添加 `PUBLIC_BASE_URL` 变量并设置真实的公网 IP 或域名，例如：
   ```env
   PUBLIC_BASE_URL=http://139.199.66.118:8000
   ```
3. 重启服务，所有依赖该 IP 的资源路径（如视频、音频 URL）将自动更新。
*注意：如果未配置 `.env`，系统将默认使用 `http://139.199.66.118:8000` 作为兜底值。你也可以直接修改 `config/base_url.py` 的默认返回值。*
